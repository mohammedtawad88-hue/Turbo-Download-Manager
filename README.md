## 🚀 Key Features

* **⚡ 16x Multi-Connection Acceleration**: Splits files dynamically into byte-level chunks using HTTP Range requests for maximum bandwidth utilization.
* **🎥 Floating Video Grabber**: Real-time sniffer overlay for YouTube and online media players with automatic video and audio stream merging.
* **🖼️ Smart Categories**: Automatically routes files into clean subdirectories (`Video`, `Images`, `Music`, `Compressed`, `Documents`, `Programs`).
* **🧩 Chrome Extension**: Seamless browser integration with one-click download capture, right-click context menus, and image saving toggles.
* **📥 Resumable Downloads**: Automatically recovers interrupted or paused downloads without data corruption.
* **🛡️ Windows System Tray & Startup**: Minimizes silently to the notification tray when closed (X button) and optionally launches on Windows boot.

## 📥 Installation

1. Download the latest installer: [**Turbo Download Manager Setup 1.0.0.exe**](https://github.com/mohammedtawad88-hue/Turbo-Download-Manager/releases/download/v1.0.0/Turbo.Download.Manager.Setup.1.0.0.exe).
2. Run the installer and follow the quick setup wizard.
3. Launch Turbo Download Manager from your Start Menu or Desktop shortcut.

---

## 🌐 Chrome Extension Setup

1. Open Google Chrome and navigate to `chrome://extensions`.
2. Enable **Developer mode** in the top-right corner.
3. Click **Load unpacked** and select the `chrome-extension` folder located inside the Turbo Download Manager installation directory (or your extracted package).
4. Click the Turbo Downloader extension icon in Chrome to ensure it shows **Connected**.
